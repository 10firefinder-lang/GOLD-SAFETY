# GOLD SAFETY ISRAEL 360 INFINITY | פריסה ל־Cloudflare

זו חבילת **Cloudflare Workers עם שמירה בענן**, ולא החבילה הקודמת של Cloudflare Pages. האתר והאחסון נמצאים בחשבון Cloudflare שלכם. אין שרת חיצוני, אין מפתח API להגדיר, ואין צורך ליצור מסד נתונים ידנית.

## התקנה ראשונה

- **פתחו את ה־ZIP**: חלצו את התיקייה `GOLD-SAFETY-Cloudflare` בשלמותה. יש צורך בחשבון Cloudflare ובמחשב עם [Node.js 22 ומעלה](https://nodejs.org/).
- **הריצו פקודה אחת**: פתחו מסוף בתיקייה שחולצה והריצו `node deploy.mjs`. ב־Windows אפשר לפתוח את התיקייה בסייר הקבצים, להקליד `cmd` בשורת הכתובת וללחוץ Enter. ב־Mac פתחו מסוף בתיקייה.
- **אשרו כניסה ל־Cloudflare**: הדפדפן ייפתח לאישור. אם Cloudflare מבקש לבחור חשבון או להפעיל כתובת `workers.dev` בפעם הראשונה, בחרו את החשבון המיועד ואשרו. לאחר הפריסה תופיע כתובת האתר ואחריה קוד גישה; שמרו את הקוד במנהל סיסמאות.

הפריסה מעלה את האתר ואת ה־Worker ויוצרת את אחסון ה־Durable Object באמצעות הגדרות שכבר נמצאות בחבילה ([Cloudflare Durable Objects](https://developers.cloudflare.com/durable-objects/get-started/)). גרירת תיקייה לשירות Pages Direct Upload אינה שיטת הפריסה של החבילה הזאת ([Cloudflare Pages Direct Upload](https://developers.cloudflare.com/pages/get-started/direct-upload/)).

## שימוש, גיבוי ועדכון

- **כמו אפליקציה**: היכנסו לכתובת ה־HTTPS ובחרו „התקנת אפליקציה”. אם הדפדפן לא מציג כפתור התקנה, ב־iPhone פתחו ב־Safari ובחרו „שיתוף” ואז „הוספה למסך הבית”. זוהי אפליקציית רשת, לא אפליקציה מחנות, ולנתוני העבודה דרוש אינטרנט.
- **מעבר מהגרסה הקודמת**: הורידו שם גיבוי JSON ופתחו בגרסת הענן „גיבוי והגדרות” ← „טעינת גיבוי”. יש לאשר החלפת נתונים. דבר לא מועבר אוטומטית.
- **שמירה וגיבוי**: הרשומות, התמונות המצורפות, טיוטות החקיקה והגדרות הסיכון נשמרות יחד בענן. המגבלה היא 12 MiB בסך הכול במרחב. גיבויי JSON וקובצי PDF ו־Excel שמורידים אינם עותק ענן אוטומטי; שמרו אותם במקום מאובטח. פתיחת מייל או וואטסאפ מכינה טיוטה בלבד; צרפו אליה קובץ בעצמכם לפי הצורך.
- **עדכונים**: השתמשו באותה תיקייה ובאותו חשבון, ושמרו על `.gold-deployment.json` שמזהה את ה־Worker. קוד הגישה נשמר גם בקובץ פרטי תחת `.gold-safety` בתיקיית הבית של המחשב שממנו פרסתם; אל תשתפו אותו. אם עוברים מחשב, העבירו את מזהה הפריסה ושמרו את הקוד במנהל סיסמאות; הפעלה באותו חשבון בלי קובץ הקוד הקיים תיצור קוד חדש. לפני עדכון הורידו גיבוי. מחיקת Worker או האחסון שלו עלולה למחוק נתונים.

האתר מיועד לבעל מרחב יחיד ואינו מחליף ייעוץ משפטי או בדיקת בטיחות מוסמכת. יש לבחון פרטיות והרשאות לפני הכנסת מידע אישי או רפואי.
